# Superstore Sales Analysis (Excel)

Business Question: Which categories, sub-categories and regions make profit or loss? How does discount affect profit?

Tools: Excel (Pivot Tables, Pivot Charts, Data Cleaning)

Key Insights:
- Technology gives the highest profit; Furniture has high sales but low profit.
- Tables, Bookcases and Supplies are loss-making.
- Central region is the weakest.
- Discounts above 30% lead to losses.

Steps: Data cleaning (date format fix, duplicate check) → Pivot Tables → Charts → Dashboard
